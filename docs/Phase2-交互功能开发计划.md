# 拾物 App · 第二阶段开发计划（真实交互）

> 状态：开发中 · 2026-08-01 · **Phase A-F 已完成并在真机验证**（数据层/首页/表单/愿望单/统计/个人页），Phase G 打磨待进行

## 一、目标

把第一版的静态界面（假数据、无交互）升级为「可真实使用」的版本：

- 所有输入框可点击并唤起输入法，按钮点击有实际效果；
- 物品/愿望单支持真正的增删改查（CRUD）；
- 数据真实持久化，重启 App 不丢失；
- 首页总览、统计页数据由真实数据实时计算；
- 个人页的导入导出、备份、回收站、设置变为可用。

## 二、现状

- Jetpack Compose（Material3）+ 单 Activity，五屏（首页/愿望/统计/我的/表单）均为静态展示；
- 数据写死在 `MockData.kt`，无存储；
- 表单无真实输入、无校验、无保存；点卡片无响应；FAB 只打开静态表单。

## 三、技术方案（决策已确认）

| 主题 | 方案 | 说明 |
| --- | --- | --- |
| 状态管理 | App 级 Repository 单例 + Kotlin StateFlow | 单 Activity 小应用，避免引入 ViewModel 依赖（本地无缓存） |
| 数据持久化 | **Room（已确认）** | kapt 编译（Room 2.6.1，避免引入 KSP 依赖） |
| 输入/键盘 | `adjustResize` + `imePadding`，滚动到焦点字段 | 保证键盘不遮挡输入框 |
| 日期选择 | Material3 `DatePickerDialog` | 无需新依赖 |
| 照片 | 相册 Photo Picker + **拍照（已确认，FileProvider）** | 相册免权限；拍照需要 FileProvider + 相机 intent |
| 导航 | 沿用当前 Tab + 表单覆盖层方案 | 不引入 navigation 库 |
| 删除 | 软删除进回收站 | 回收站 30 天后自动清除（保留逻辑） |
| 交互路径 | 点卡片 → **详情页（新增）** → 编辑表单 | 已确认：详情页提供退役/复役、编辑、删除入口 |

### 补充需求（已并入各阶段）

1. **首页顶栏搜索图标**：移除（界面下方已有搜索栏，顶栏保留分享按钮）。
2. **心愿单录入表单与物品表单差异**：已核实设计稿无心愿表单示意；心愿字段为「名称、分类、预计价格、优先级（HIGH/MEDIUM/DREAM）、已攒金额（可选）、备注（可选）」，不含照片/购入日期/日均成本。物品表单保持原字段。
3. **退役功能**：
   - `Item` 增加 `retired`（是否退役）与 `retirementDate`（退役日期）；
   - 日均成本规则：使用中 = 价格 ÷ 距购入日期天数；已退役 = 价格 ÷ 服役天数（购入 → 退役）；
   - 详情页提供「退役」（选退役日期，默认今天）与「复役」操作；
   - 首页支持过滤：全部 / 使用中 / 已退役。

## 四、分阶段任务

### Phase A：数据层与种子数据

- [ ] 定义数据模型：`Item`（名称/分类/价格/购入日期/照片路径/备注/回收标记/创建时间）、`Wish`（名称/分类/价格/优先级/备注/已攒金额/完成状态）、`Category`（可选自定义分类）
- [ ] 实现 `Repository`：CRUD + 查询（按关键词/分类过滤、回收站列表、统计聚合）
- [ ] 首次启动写入示例数据（把现有 MockData 迁移成种子数据），保证界面不空

### Phase B：首页真实化

- [ ] 总览卡实时计算：总价值、物品总数、日均总成本、本月新增
- [ ] 搜索框：真实输入、实时过滤（名称/品牌/标签），键盘可唤起（顶栏搜索图标移除）
- [ ] 点卡片 → 打开「物品详情页」
- [ ] 详情页：物品信息、服役状态、退役/复役（日期选择）、编辑、删除
- [ ] 退役过滤：全部 / 使用中 / 已退役 三档切换
- [ ] FAB → 新增表单
- [ ] 空状态：无物品时显示引导文案 + 新增按钮

### Phase C：表单真实化（核心）

- [ ] 名称、价格输入框：点击唤起输入法，价格限制数字+小数
- [ ] 分类：真实选择（选中高亮），支持「+ 新建」自定义分类
- [ ] 购入日期：DatePicker 选择，默认今天
- [ ] 照片：Photo Picker 选图，缩略图预览、可删除、上限 6 张
- [ ] 校验：名称必填、价格 ≥ 0，错误提示
- [ ] 保存：新增写入 / 编辑更新，保存后自动计算日均成本
- [ ] 删除：编辑模式下出现「删除物品」→ 二次确认 → 移入回收站
- [ ] 键盘避让：`imePadding` + 滚动到焦点字段

### Phase D：愿望单真实化

- [ ] 心愿列表由真实数据渲染
- [ ] 新增/编辑心愿表单（**独立字段**：名称/分类/预计价格/优先级/已攒金额/备注）
- [ ] 优先级选择（HIGH / MEDIUM / DREAM）
- [ ] 标记「已购买」→ 自动转为物品（带入价格/分类），从心愿单移除
- [ ] 删除心愿（移入回收站或直接删除）
- [ ] 顶部概览实时计算：预计总费用、已攒预算、完成度

### Phase E：统计真实化

- [ ] 总价值趋势：按月汇总真实数据，画折线（近半年/全年切换）
- [ ] 分类占比：真实金额计算环形图 + 图例
- [ ] 日均成本 TOP 3：真实计算
- [ ] 范围筛选（本月/近半年/全年）真正生效

### Phase F：个人页真实化

- [ ] 导入物品：解析 CSV / JSON 文件（系统文件选择器）
- [ ] 导出数据：生成 CSV / JSON 并分享/保存
- [ ] 自动备份：每日快照 JSON 到本地，显示备份数量与大小
- [ ] 回收站：列表、恢复、彻底删除、30 天自动清理
- [ ] 设置：货币单位、分类管理、外观主题（暖白/深色）持久化
- [ ] 关于页：版本号真实显示

### Phase G：打磨与回归

- [ ] 空状态/错误提示/加载态统一
- [ ] 键盘弹出、旋转、深色主题回归
